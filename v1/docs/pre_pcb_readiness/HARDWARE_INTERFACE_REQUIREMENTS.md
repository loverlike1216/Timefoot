# 后续硬件设计输入与验证条件

本文件只定义预设计要求。无原理图/PCB/制造/实物连接授权。

## 信号角色和电压

| 接口 | 电气候选 | 必须确认 |
|---|---|---|
| 中央CLOCK/SYNC分配 | 3.3V逻辑源→专用LVDS fanout→100ohm差分线→接收器→LVCMOS33 FPGA | 共模范围、正负极性、端接、电源时序、匹配偏差、SYNC DC传输 |
| 节点DATA SDR | 单端3.3V、点到点、短连接、每个信号独立方向 | 对应Bank实测3.3V，现有串阻、负载和其它驱动，反射/串扰/地弹 |
| FRAME CREDIT | 单端3.3V慢变化、held level、接收端XPM同步 | 不能形成快组合beat loop；断线安全需管理fault机制 |
| 管理串行 | 3.3V、外部25MHz自由运行，CS/MOSI/MISO/ready | 主机边沿符合STA；多节点需独立CS/总线仲裁，不能直接并联MISO输出 |
| monitor | 各节点独立50MHz本振候选 | EBAZ X5是否实际装配、频率与输出；AX U18板载XO只能作输入，不能并接外部输出 |
| marker/qualification/event/fault/reset | 3.3V明确单驱动；fault/reset安全态 | marker相位实测，资格不能常数；reset电气容忍、断电反灌和控制器可用性 |

不允许把5V或EBAZ DATA电源针当GPIO。AX J10/J11:1/37/38为GND，2为5V，39/40为3.3V（原资料）；EBAZ社区DATA1/2/3:1/3/10/12为GND，2/4为VCC-DATA输入电源相关网络，其电压不应推断为3.3V。所有电源针在候选跨板信号线束中留空、绝缘；仅连接核实的信号和回流地。绝不通过未核对的排针给其它整板供电。

## 传播与采样预算

DATA要求发送PAD相对转发时钟下降沿偏移-1..2ns，clock/data相对连接路径差-1..+1ns，故RX输入相对下降沿范围-2..3ns。50MHz中心采样半周期10ns。实际签核见TIMING_CONSTRAINT_SPEC；板级传播绝对值可以大于此**相对差**，但不可超出协议两端flush/状态监督要求。候选单端线束长度先限定<=20cm作为SI验证起点，不能仅凭长度满足50MHz：主要风险是边沿速率、返回路径及连接器阻抗。每个高速信号有邻近GND，减少支路和未端接stub。

CLOCK/SYNC差分线候选100ohm，长度先限定<=1m、各节点路径匹配目标<=5cm（传播差需要实测）。线缆速度因子/连接器延迟UNKNOWN；不能把厘米直接当作测得ps。CLOCK/SYNC的板内接收器至FPGA路径及不同接收器器差必须计入资格窗口。单纯使用相同线长不足以保证0.5..3ns SYNC接口要求。

## 接收与电源

SN65LVDT2带内部差分端接，不能再默认并接第二个100ohm；SN65LVDS2版本无内端接，需要外置。仅为接收器选型输入，具体极性、管脚号和封装方向在获得下一阶段授权后按选定订货号原图逐脚复核。失能fanout为Hi-Z，接收器可能failsafe输出高；禁止假设失能后CLOCK/SYNC恒低。安全性依赖qualification、reset和Session。

中央分配模块独立受控电源，候选3.3V/1A预算用于接口模块，不包括四块Zynq整板。输入候选5V（更高输入需重新计算buck热/保护）。接收器放到各节点适配处时从当地已核实电源供电；不同板3.3V不能直接并联。留PG/过流/反接/ESD需求，地电位差必须落在接收器推荐范围。跨板长距离/不同电源环境超范围时应重新选隔离/收发方案，不能带条件签核后盲插。

## 下一阶段必须验证的项目

逐板记录型号/修订/照片/断电通断、排针pin1方向、Bank电压、板载并联驱动、每条串阻和信号去向。测50MHz占空比/幅值/上升时间，CLOCK与SYNC相对到达时间、同事件PAD偏差、每种DATA宽度的眼图/误码/拥塞恢复、失电和插拔安全态。若任一预算不满足，先调整器件/相位/布线并重新STA与仿真；不得自动降低同步验收标准。所有这些当前均NOT_HARDWARE_VERIFIED。
